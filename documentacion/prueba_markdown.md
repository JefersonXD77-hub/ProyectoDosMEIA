
# Prueba de almacenamiento Markdown

## Proyecto Dos - MEIA

Universidad de San Carlos de Guatemala

### Objetivo
Comprobar que el Sistema de Gestión Documental permite almacenar, descargar y recuperar archivos Markdown mediante MongoDB y GridFS.

### Tecnologías utilizadas
- Angular 21
- Node.js
- Express
- MongoDB
- GridFS

### Resultado esperado
El archivo debe conservar su contenido original después de subirlo y descargarlo desde el sistema.

**Estado:** Prueba de funcionamiento.
